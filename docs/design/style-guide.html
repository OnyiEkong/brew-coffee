07 Motion

Motion

Warm, intentional animation. Spring easing for tactile interactions, smooth ease for state transitions. Nothing hurried, nothing sluggish.

cubic-bezier(0.34, 1.56, 0.64, 1)
300ms · Button press, card hover
ease-out
cubic-bezier(0, 0, 0.2, 1)
